## ★ まだ必要なファイル（2点）

### logo.jpg
既存の `/toryumon/` フォルダからコピーしてください。

### hero.png
ファーストビューの背景写真。既存のものを流用するか、差し替える場合は下記推奨。

| 項目 | 推奨 |
|---|---|
| サイズ | 2400 × 1400px |
| 形式 | JPEG（`hero.png` の名前で保存 or HTML側のパスを変更） |
| 容量 | 400〜700KB |
| 構図 | **人物は右寄り／顔は上から20〜40%の高さ** |
| 左3分の1 | 背景・余白（テキストが乗ります） |

※ PCは全面表示、スマホは上部の帯（高さ280〜380px）に切り抜かれます。

## 4大特典の配布について

MOSHにはファイルの直接アップロード機能がないため、URLでの配布になります。
GitHub Pages を使っているので、リポジトリに `dl/` フォルダを作り、
Excelファイルを置いて、そのURLを申込者向けサイトに記載するのが最適です。

例：`https://markey-consulting.com/dl/toryumon-bonus-a7k3f9.xlsx`

※ ファイル名にランダム文字列を入れると、実質的に非公開にできます。
