# コラム原稿の書き方

原稿は `column/_src/` に Markdown で置き、`python3 tools/build_column.py` で HTML にします。

## 先頭の設定

```
---
title: 記事タイトル
description: 検索結果に出る説明（120字前後）
framework: 営業マインド | 営業知識・営業スキル | 商談戦略 | アピアランス・トナリティ | 顧客管理
audience: 対象（例: 住宅営業の新人〜中堅）
published: 2026-10-21
tags: タグ1, タグ2
draft: true   ← 公開するときは、この行を消す
---
```

## 強調の使い方（全記事共通）

| 書き方 | 見え方 | 使いどころ |
|---|---|---|
| `**太字**` | 太字 | 結論、キーワード |
| `==黄色マーカー==` | 黄色の蛍光ペン | 一番伝えたい1文・1フレーズ |
| `%%赤字%%` | 赤字 | 注意点、やってはいけないこと、数字 |

1つの節に、強調は多くても2〜3か所にします。全部が目立つと、どれも目立たなくなります。

## 自動で付くもの

- 記事の終わりに、住宅営業登竜門（動画講座）への案内が付きます。
- 目次は、`##` の見出しから作ります。
- `## よくある質問` の下に `### 質問` と答えを書くと、FAQ になります。
